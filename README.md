# Amna Hafeez — Portfolio

Personal portfolio of **Amna Hafeez**, a Software Engineering student at FAST-NUCES (Class of 2028).

**Live site:** https://amna-hafeez-portfolio.vercel.app

## What's on the site

- **Hero and About:** who I am, what I build, and a downloadable resume
- **Skills:** languages, frameworks, concepts and tools
- **Projects:** 9 projects, including Katas Raj Heritage 3D, a COLMAP 3D reconstruction of Mohenjo-daro's Great Bath, RAHBAR, ScamShield Live and ClinicQ
- **Experience & Leadership:** my Platform & Web Engineering internship with TechRealm × PreserveMy.World, plus volunteering and event organizing
- **Certifications:** with certificate images where available
- **Contact:** email, GitHub and LinkedIn

## Built with

- React 19 and Vite
- Tailwind CSS 3
- Framer Motion for animations
- Lenis for smooth scrolling
- tsParticles for the background effect
- Deployed on Vercel

## Run it locally

You need Node.js 20.19 or newer.

```bash
git clone https://github.com/Anfey-SE/portfolio.git
cd portfolio
npm install
npm run dev
```

Then open http://localhost:5173.

To make a production build:

```bash
npm run build
npm run preview
```

## Project structure

- `src/constants/data.js`: all the content (text, projects, skills, certifications)
- `src/components/sections/`: the page sections
- `src/components/ui/`: reusable pieces such as project cards
- `public/`: resume PDF and images
